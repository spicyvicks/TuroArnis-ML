# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Horizontal flipping kills side class discrimination — Horizontal flip augmentation swaps left/right side positions, but labels remain unchanged. This makes `stick_left_side` and `stick_right_side` impossible to learn. Real-only test: `stick_left_side` = 6.7%, `stick_right_side` = 0%. Other left/right pairs unaffected because body pose (arm/shoulder/leg/hand joints) provides disambiguation cues that side positions lack.
- [ ] CONSTRAINT: Synthetic 3x may overfit — Train accuracy 86% vs real-only test 56.6% = ~29 point gap. Synthetic perturbation artifacts are being memorized. Prior best (57.6%) was with buggy generator that forced all sticks to right hand, creating an artificial discriminative signal.
- [ ] CONSTRAINT: Neutral class has no stick-dependent features — 14 stick features were stripped from neutral templates. Model must classify neutral purely from pose. This is fine but means neutral accuracy (26.7%) reflects pose-only discrimination difficulty.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Horizontal flip on side-positioned classes | Flipping `stick_left_side` image makes it `stick_right_side` visually but keeps `stick_left_side` label. Model learns left/right side are the same class. | blocking | Either remove horizontal flip augmentation, merge side classes into single "stick_side", or accept 0% side class accuracy |
| Hardcoding stick hand in synthetic generator | Prior `2c_generate_synthetic_features.py` hardcoded stick reattachment to node 16 (right hand) regardless of `stick_right_hand` metadata. This accidentally helped right-hand-dominant classes but broke left-hand techniques. | blocking | Always read `stick_right_hand` metadata and attach stick to correct hand node (15 or 16) |
| Evaluating on synthetic-augmented test | Training validation includes 1x synthetic test data, which inflates accuracy vs pure real data (54.3% mixed vs 56.6% real-only). Synthetic test is closer to training distribution. | advisory | Always run `hybrid_classifier/evaluate_real_only.py` to see true real-world generalization |
| Assuming more synthetic = better | 3x synthetic gave 54.3% vs baseline 39.4% (no synthetic), but prior buggy 5x gave 57.6%. Distribution shift from excessive synthetic may hurt generalization. | advisory | Test 1x and 2x synthetic ratios, don't blindly increase |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
