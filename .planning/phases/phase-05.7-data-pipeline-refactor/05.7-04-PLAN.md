  <action>
    Generate comprehensive comparison of all three viewpoint models:
    
    ```python
    import json
    
    models = {}
    for viewpoint in ['front', 'left', 'right']:
        with open(f'hybrid_classifier/logs/history_{viewpoint}.json') as f:
            h = json.load(f)
        models[viewpoint] = {
            'best_val': max(h['val_acc']),
            'final_train': h['train_acc'][-1],
            'epochs': len(h['val_acc']),
            'gap': h['train_acc'][-1] - max(h['val_acc'])
        }
    
    print("=" * 60)
    print("PER-VIEWPOINT MODEL COMPARISON")
    print("=" * 60)
    print(f"{'Model':<10} {'Best Val Acc':<12} {'Final Train':<12} {'Gap':<8} {'Epochs':<8} {'Status'}")
    print("-" * 60)
    
    overall_pass = True
    for vp, m in models.items():
        if m['best_val'] >= 0.70:
            status = "PASS"
        elif m['best_val'] >= 0.60:
            status = "RETRY"
            overall_pass = False
        else:
            status = "INVESTIGATE"
            overall_pass = False
        print(f"{vp:<10} {m['best_val']:<12.1%} {m['final_train']:<12.1%} {m['gap']:<+8.1%} {m['epochs']:<8} {status}")
    
    print("-" * 60)
    avg_acc = sum(m['best_val'] for m in models.values()) / 3
    print(f"Average validation accuracy: {avg_acc:.1%}")
    print(f"Overall status: {'ALL PASS' if overall_pass else 'NEEDS ATTENTION'}")
    
    # Save summary
    with open('hybrid_classifier/logs/model_comparison.json', 'w') as f:
        json.dump(models, f, indent=2)
    ```
    
    Report all three statuses for checkpoint.
  </action>
