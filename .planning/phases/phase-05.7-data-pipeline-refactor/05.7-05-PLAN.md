## Deployment Package Structure
```
deployment_package/
├── src/
│   ├── feature_extraction.py    # Already exists - feature extraction

└── requirements.txt             # CPU-only dependencies
```

## Model Registry Format (active_models.json)
```json
{
  "version": "1.0",
  "type": "per_viewpoint",
  "viewpoint_models": {
    "front": "models/model_front.pth",
    "left": "models/model_left.pth",
    "right": "models/model_right.pth"
  },
  "metadata": {
    "trained_at": "2026-04-23",
    "accuracy_front": "72.3%",
    "accuracy_left": "71.8%",
    "accuracy_right": "73.1%"
  }
}
```

## Inference Flow
1. Detect viewpoint from image filename or EXIF
2. Load corresponding model: `active_models.json` → `viewpoint_models[viewpoint]`
3. Extract features using `feature_extraction.py`
4. Run inference using `model_architecture.py`
5. Return classification result
</context>
